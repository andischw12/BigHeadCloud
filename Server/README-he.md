# שמירת נתונים — ענף SaveLife של "ראש גדול 2"

הענף הזה משתמש ב־`UserArrayEnum`, ב־`UserAvatarArr` וב־`UserStoreMatrix`, ולכן
ההתאמה נעשתה מחדש למבנה שלו. ה־JSON הנשמר כולל את `StoreInfo`, שמייצג את פריטי
החנות מהמטריצה הדו־ממדית.

## שימוש בטבלה שכבר נוצרה

אין צורך ליצור את הטבלה שוב. אפשר להריץ את `00-verify-existing-schema.sql` בלבד;
הוא אינו משנה נתונים ומוודא שהטבלה `BigHeadGameData` מכילה את העמודות הנדרשות.

יש להעלות את `BigHeadGameData.asp` אל `/asp/`, ליד `common.asp`, ואז לבנות מחדש
את WebGL. ה־ASP קורא את ה־OID מהקוקי `UserSettings` בצד השרת.

## fallback בדפדפן

כל שמירה נכתבת קודם ל־`localStorage` תחת מפתח שמבודד לפי OID ושחקן. עותק שלא
אושר בשרת נשאר `dirty`, נטען בפעם הבאה ונשלח שוב. אם השרת אינו זמין, המשחק
ממשיך מהעותק המקומי. נתונים ישנים מהמפתחות `BigHead_2N`, `BigHeadN_2` ו־`BigHeadN`
נתמכים, אך אינם דורסים נתון שרת קיים.

`PlayerPrefs` של צליל, חדר, נושא וסביבת המשחק האחרונים הם מצב מקומי זמני ואינם
חלק מנתוני החשבון.
