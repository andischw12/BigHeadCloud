# שמירת נתוני "ראש גדול 2"

## פריסה

1. להריץ במסד הנתונים את `01-create-big-head-game-data.sql`.
2. להעתיק את `BigHeadGameData.asp` לתיקיית `/asp/` באתר, ליד `common.asp`.
3. לבנות מחדש את גרסת WebGL. `Assets/Plugins/GameUserData.jslib` פונה ל־`/asp/BigHeadGameData.asp`.

## התנהגות

- ה־ASP קורא את `OID` ישירות מהקוקי `UserSettings`; הלקוח אינו שולח OID.
- כל אחד מארבעת פרופילי הילדים נשמר לפי `(OID, GameKey, PlayerSlot)`.
- בכל שינוי נכתב קודם `localStorage`, ורק לאחר מכן נשלחת שמירה מקבילה לשרת.
- עותק מקומי שלא סונכרן מסומן `dirty`; בטעינה הבאה הוא גובר על עותק שרת ישן ונשלח שוב.
- אם השרת אינו זמין, המשחק נטען מהדפדפן. מפתחות ישנים (`BigHead_2N` ו־`BigHeadN`) מועברים אוטומטית.

## נקודות שמירה שמופו

ה־JSON של `KidUser` כולל שם, מצב פעיל, מגדר, יהלומים, ניקוד, ניצחונות/הפסדים,
תשובות נכונות, שימוש בעזרים, זמן משחק, הוצאות, דרגה, אווטאר, פריטי חנות וניקודי
שבת/חנוכה/פורים. הוא נשמר לאחר רכישה, החלפת אווטאר, עדכון נתון שחקן, יצירת
פרופיל, מחיקת פרופיל ובסיום משחק.

`PlayerPrefs` משמש בנפרד להגדרות/מצב זמני (צליל, משחק חוזר, חדר ונושא אחרון),
ולכן נשאר מקומי בלבד. תוצאת מנצח/מפסיד הועברה מה־ASP הישן של ה־CRM לפעולת
`result` ונשמרת בטבלה `BigHeadGameResults` לפי OID.
